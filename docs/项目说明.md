# Sw 语言编译器（swcc）——项目说明与当前进度

## 项目

Sw 编程语言编译器，Rust workspace（`sw_common` / `sw_frontend` / `sw_semantic` /
`sw_codegen_cranelift` / `swc`）。后端用 Cranelift 进程内生成机器码 + 内嵌 lld
链接；SDK 含预编译 C 运行时，终端用户解压即可使用，无需另装 clang。支持 Windows / Linux / macOS × x86_64 /
aarch64（Linux 可 musl 静态链接）。语法是 JS 风格，正在补 Rust 风格特性。

## 当前进度（最近完成，已全部提交）

1. 多文件/循环 import：模块加载/绑定与检查/降级拆两阶段，两个 `.sw` 可互相调用
   （lib-a ↔ lib-b）
2. 跨文件全局变量（export const/let 共享读写）
3. trait 约束：`where T: Shape`、泛型类 `implements Container<T>`（泛型接口实例化）
4. ADT 枚举 + match：`enum Option<T> { Some(T), None }`、模式匹配/解构/穷尽检查
5. Result + `?` 运算符（std/result）
6. 数组迭代器 `map/filter`（内联循环）、切片 `a[1:3]`
7. `@test` + `swc test`：std/test 断言库（assert/expect_eq<T> 支持数组/struct/
   expect_true/fail），runner 捕获异常
8. 跨模块泛型函数实例化（结果表按模块取）
9. 标准库：std/io fs os string math time json unicode encoding net array map
   result test sync
10. CI 三平台（Windows/Linux/macOS）配置全量 examples 回归 + `swc test`

## 常用命令

```bash
# 构建
cargo build --release -p swc

# 运行 / 测试
target/release/swc run examples/xxx.sw
target/release/swc test examples/probe-test.sw

# 全量回归（本机无系统 python 时用 bundled python）
python tools/run-examples.py target/release/swc.exe

# 单测
cargo test --release
```

## 已知限制

- Windows aarch64 暂不支持（Cranelift COFF 限制）
- 已提供 `std/thread` 和 `std/task`：TLS 异常帧、线程注册、协作 safepoint、停世界 GC、
  任务状态/异常隔离和协作取消。当前任务入口限定为 `() => int` 闭包，`await` 等待
  `Task<int>`；块闭包内含循环的控制流降级仍在完善。
- `swc lsp` 已支持诊断、类型悬停、定义跳转和增量同步；调试信息待完善
- 全局变量初始化限编译期常量
