# 04 内存模型

状态：规范基线

## 1. 值类型与引用类型

| 类别 | 类型 | 语义 |
|---|---|---|
| 值类型 | `bool`、数值、`char`、`struct`、`enum` | 赋值/传参拷贝字节，无共享 |
| 引用类型 | `string`、`T[]`、`class` 对象 | 赋值/传参共享同一份数据，由 GC 管理 |
| 原生指针 | `ptr<T>` | 裸指针，不参与 GC 所有权管理 |

## 2. 内存管理

- v0.1 运行时采用**保守式标记-清除 GC**：扫描原生栈、寄存器溢出区与程序数据段，
  字符串/数组/class/闭包全部经 GC 分配器管理，达到阈值自动回收不可达块。
- 堆内引用（类字段、数组元素指向其它 GC 对象）在标记阶段一并扫描，循环引用也能回收。
- 保守式扫描只产生“少回收”的误判，不会产生悬垂引用。异常对象由 GC 分配；异常帧
  是运行时栈帧元数据，在 `try` 退出时显式弹出。
- 用户不可手动 `free` 或调用析构；当前没有析构函数实现。

## 3. 拷贝语义

- 值类型：逐字节拷贝，结构体字段中的引用类型字段仍指向同一 GC 管理对象。
- 引用类型：共享引用，不深拷贝。
- 数组赋值 `let b = a;` 共享同一块缓冲；当前标准库未提供通用 `copy()`。
- 函数参数按"共享引用"传递：被调函数可修改引用对象的字段（如数组元素），但重新赋值参数本身不影响调用方。

## 4. 生命周期

- 局部变量离开作用域后不再作为活动根；其引用对象在后续 GC 中不可达时回收。
- `defer` 在当前作用域退出时按逆序执行；它用于文件、socket、HTTP 会话和进程等
  非托管资源的显式清理，并覆盖 `return`、循环控制流与异常传播路径。
- 对象字段中的引用由标记阶段递归扫描；对象不可达后整体回收。
- `weak<T>` 弱引用在 v0.2 提供；GC 方案下循环引用可回收，无需手动断链。

## 5. 数组

- `T[]` 是动态数组：运行时保存指针、长度、容量。
- 越界索引、负数索引是运行期错误。
- `arr.length` 只读；`arr.push(x)`、`arr[i] = v` 可写。
- 数组元素为引用类型时，元素由 GC 标记阶段递归扫描。

## 6. 字符串

- `string` 是不可变 UTF-8 文本；比较、拼接、索引按字符（`char`）语义。
- 字符串拼接创建新字符串；`s[i]` 返回第 `i` 个 Unicode 标量值（`char`）。
- 模板字符串 `${expr}` 在编译期展开为拼接/格式化调用。

## 7. 全局变量

- 顶层 `const`：编译期常量，只读数据段。
- 顶层 `let`：程序级存储期全局，可在函数内读写。
- 当前全局初始化仅支持编译期常量；浮点、字符串、数组等初始化仍待补充验证。

## 8. 平台保证

- 指针宽度与目标平台一致（64 位平台 8 字节）。
- 结构体布局、对齐按目标平台 ABI 规则确定（见 07 平台与ABI）。
- GC 管理对象不会被用户显式释放；保守式扫描可能延后回收，但不会主动产生悬垂引用。
