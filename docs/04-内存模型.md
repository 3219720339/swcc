# 04 内存模型

状态：规范基线

## 1. 值类型与引用类型

| 类别 | 类型 | 语义 |
|---|---|---|
| 值类型 | `bool`、数值、`char`、`struct`、`enum` | 赋值/传参拷贝字节，无共享 |
| 引用类型 | `string`、`T[]`、`class` 对象 | 赋值/传参共享同一份数据，引用计数 +1 |
| 原生指针 | `ptr<T>` | 裸指针，不参与所有权，仅 unsafe 解引用 |

## 2. 引用计数

- `string`、`T[]`、`class` 对象由运行时统一引用计数管理。
- 变量赋值、传参、字段写入都会增加引用计数；变量离开作用域、字段被替换、函数返回时释放（引用计数 -1）。
- 计数归零时释放底层内存；`string` 与 `T[]` 的缓冲由运行时分配器管理。
- 用户不可手动 `free` 或调用析构；析构（`destructor`）由引用计数归零触发。

## 3. 拷贝语义

- 值类型：逐字节拷贝，结构体字段中的引用类型字段按引用计数规则共享。
- 引用类型：共享引用，不深拷贝。
- 数组赋值 `let b = a;` 共享同一块缓冲；需要独立副本时显式调用 `copy()`（标准库，v0.2）。
- 函数参数按"共享引用"传递：被调函数可修改引用对象的字段（如数组元素），但重新赋值参数本身不影响调用方。

## 4. 生命周期

- 局部变量在其声明所在块退出时释放，按声明逆序。
- `defer` 表达式在当前作用域退出时执行（LIFO），先于该作用域变量的释放。
- 对象字段的引用跟随对象生命周期；父对象释放时，子引用计数相应递减。
- 循环引用（如双向链表）无法自动回收，v0.1 会产生内存泄漏；`weak<T>` 弱引用在 v0.2 提供。

## 5. 数组

- `T[]` 是动态数组：运行时保存指针、长度、容量。
- 越界索引、负数索引是运行期错误。
- `arr.length` 只读；`arr.push(x)`、`arr[i] = v` 可写。
- 数组元素为引用类型时，元素赋值遵守引用计数。

## 6. 字符串

- `string` 是不可变 UTF-8 文本；比较、拼接、索引按字符（`char`）语义。
- 字符串拼接创建新字符串；`s[i]` 返回第 `i` 个 Unicode 标量值（`char`）。
- 模板字符串 `${expr}` 在编译期展开为拼接/格式化调用。

## 7. 全局变量

- 顶层 `const`：编译期常量，只读数据段。
- 顶层 `let`：程序级存储期全局，初始化在 `main` 前完成。
- 全局引用类型的初始化在运行期执行（v0.2 支持前，v0.1 只允许常量初始化式）。

## 8. 平台保证

- 指针宽度与目标平台一致（64 位平台 8 字节）。
- 结构体布局、对齐按目标平台 ABI 规则确定（见 07 平台与ABI）。
- 禁止悬垂引用：编译器保证引用计数对象的释放总是发生在最后一个引用之后。
