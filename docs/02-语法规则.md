# 02 语法规则

状态：规范基线

> 本文为语法规范基线；**当前实际能力以 docs/08-能力清单.md 与 examples/
> 为准**，本文与之一致处优先，冲突处以后者为准（避免 v0.1 早期规划残留）。

## 1. 基本原则

- 代码块用 `{ }`，不使用缩进形成结构。
- 语句结束必须写 `;`（块、`if/while/for/switch/try` 等控制结构本身除外），**不执行自动分号插入**。
- 顶层只能出现导入、函数、结构体、枚举、类、接口、类型别名、全局变量/常量声明。
- 表达式优先级由本文件统一规定，解析器不根据换行改变表达式结构。
- 完整机器可读定义见 [grammar/sw.ebnf](grammar/sw.ebnf)。

## 2. 源文件

```text
sourceFile := item* EOF
item := importDeclaration
      | export? functionDeclaration
      | export? structDeclaration
      | export? enumDeclaration
      | export? classDeclaration
      | export? interfaceDeclaration
      | export? typeAliasDeclaration
      | export? variableDeclaration ";"
```

## 3. 导入

```js
import { println, print as write } from "std/io";
import * as fs from "std/fs";
import "./side_effect";
```

- 路径可以是相对路径（`"./foo"`，自动补 `.sw`）或标准库路径（`"std/io"`）。
- 不支持默认导出与默认导入。

## 4. 变量与常量

```js
let count: int = 0;
let inferred = 10;        // 由初始化式推导
const name = "Sw";        // 不可重新赋值
const mask: u32 = 0xFF;
```

规则：

- `let` 可重新赋值；`const` 不可重新赋值（但引用类型的内容仍可变）。
- 类型标注与初始化表达式至少提供一个；两者都提供时类型检查初始化式。
- 顶层 `const` 是编译期常量；顶层 `let` 是程序级全局变量。
- 不支持 `let a = 1, b = 2;`，一条语句只声明一个名字。
- 支持解构：`const [a, b] = arr;`、`const { x, y } = obj;`、重命名
  `{ x: renamed }`（详见 docs/08-能力清单.md）。

## 5. 函数

```js
function add(a: int, b: int): int {
    return a + b;
}

function connect(host: string, port: int = 8080): bool { ... }

function identity<T>(value: T): T { return value; }
function tagged<T>(value: T): T where T: Tagged { ... }

extern c function native_add(a: i32, b: i32): i32;

const double = (x: int): int => x * 2;
const greet = (name: string) => `hi ${name}`;
```

规则：

- 返回类型可省略，由 `return` 语句推导；所有分支必须一致。
- 函数体必须存在；`extern` 函数用 `;` 代替函数体。
- 支持顶层同名函数重载，按参数类型选择。
- 箭头函数参数：上下文能推导类型时可省略标注（如回调参数）；否则必须标注。
- 箭头函数体可以是表达式或块。

## 6. 结构体、枚举、类、接口

```js
struct Point {
    x: float;
    y: float;
}

enum Color {
    Red,
    Green,
    Blue,
}

class Shape {
    constructor(public name: string) { }
    area(): float { return 0; }
}

class Circle extends Shape {
    constructor(name: string, radius: float) {
        super(name);
        this.radius = radius;
    }
    override area(): float { return 3.14 * this.radius * this.radius; }
}

interface Drawable {
    draw(): void;
}
```

规则：

- 字段声明：`identifier: type [= expr] ;`，前缀 `public/private/protected/internal/static`。
- `constructor` 构造；`destructor` 析构（Sw 扩展，作用域退出时调用）。
- `property` 属性块内含 `get`/`set` 访问器。
- 类方法默认非虚；`virtual` 标记虚方法，`override` 覆盖父类虚方法。
- 接口只含方法签名；接口引用通过虚表派发。
- `struct` 是值类型；`class` 是引用类型。

## 7. 语句

```text
statement := block
          | variableDeclaration ";"
          | ifStatement | whileStatement | forStatement | forEachStatement
          | switchStatement | tryStatement | throwStatement | deferStatement
          | "break" ";" | "continue" ";" | "return" [expression] ";"
          | expressionStatement ";"
```

### 7.1 条件与循环

```js
if (cond) { } else if (cond2) { } else { }
while (cond) { }
for (let i = 0; i < n; i++) { }
for (const item of items) { }
```

- `for` 三部分都可省略（`for (;;)`）。
- `for...of` 迭代 `T[]`、string 或实现迭代协议的类型。

### 7.2 switch

```js
switch (code) {
    case 0:
        ...
        break;
    case 1:
    case 2:
        ...
        break;
    default:
        ...
}
```

- `case` 值是编译期常量（整数、字符、字符串、枚举成员）。
- 不自动落空（fall-through），与 JS 一致：`case` 块末尾必须 `break`/`return`/`throw`。

### 7.3 异常

```js
try {
    risky();
} catch (e) {
    handle(e);
} catch (e: HttpError) {
    handleHttp(e);
} finally {
    cleanup();
}

throw new Error("failed");
```

- `catch` 不写类型时捕获所有异常。
- `finally` 无论是否异常都执行。

### 7.4 defer

```js
defer file.close();
```

`defer` 在当前作用域退出时按声明逆序执行；`return`、`break`、`continue`、
异常传播以及 `try/catch/finally` 的异常路径都会执行仍活跃的清理项。

## 8. 表达式与优先级

优先级从低到高：

| 优先级 | 类别 | 运算符 | 结合性 |
|---|---|---|---|
| 1 | 赋值 | `= += -= *= /= %= &= \|= ^= <<= >>= ??=` | 右 |
| 2 | 三元 | `?:` | 右 |
| 3 | 空值合并 | `??` | 左 |
| 4 | 逻辑或 | `\|\|` | 左 |
| 5 | 逻辑与 | `&&` | 左 |
| 6 | 位或 | `\|` | 左 |
| 7 | 位异或 | `^` | 左 |
| 8 | 位与 | `&` | 左 |
| 9 | 相等 | `== !=` | 左 |
| 10 | 关系 | `< <= > >=` | 左 |
| 11 | 移位 | `<< >>` | 左 |
| 12 | 加法 | `+ -` | 左 |
| 13 | 乘法 | `* / %` | 左 |
| 14 | 幂 | `**` | 右 |
| 15 | 一元 | `! ~ + - ++ -- await` | 右 |
| 16 | 后缀 | `() [] . ?. ++ --` | 左 |
| 17 | 主表达式 | 字面量、标识符、`this`、`super`、分组、数组、对象、模板、`new`、箭头函数 | — |

主表达式：

```js
123  "str"  `tpl ${x}`  true  null     // 字面量
foo  this  super                          // 名字
(a + b) * c                               // 分组
[1, 2, 3]                                 // 数组字面量
{ x: 1, y: 2 }                            // 对象字面量（需目标类型）
new Point(1, 2)                           // 构造
(x: int) => x * 2                         // 箭头函数
```

后缀：

```js
obj.field        // 字段/方法访问
obj?.field       // 空值安全访问
arr[0]           // 索引
func(a, b)       // 调用
obj.property = v // 属性赋值（走 set）
```

## 9. 明确不支持的语法（给出明确错误）

- `var`、`undefined`、`typeof`、`instanceof`、`do...while`
- `===`、`!==`、`>>>`
- 默认导入、CommonJS `require`
- 自动分号插入（缺少 `;` 报语法错误）
