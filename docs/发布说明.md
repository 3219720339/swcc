## v0.1.2（2026-08-15）

### 修复
- 批 11 崩溃根因：`regex_captures` 无匹配时返回空数组，而 Sw 的 `&&` 编译为
  按位与（不短路），调用方访问空数组元素得 NULL 字符串、`string_eq` 解引用
  崩溃（0xC0000005）。现无匹配返回与组数等长的空串数组，符合文档
  「未参与匹配的组返回空串」。
- Windows SDK 分发缺陷：`make-sdk.py` 漏拷 `libole32.a` 与 `libws2_32.a`，
  导致分发版链接网络（ws2_32）与 COM（ole32）相关程序失败；0.1.2 补齐并加
  存在性检查，缺失即构建报错。

### 分发 / 工程
- 版本号升至 0.1.2（根 Cargo.toml `[workspace.package] version`）。
- CI 新增 Windows SDK artifact 冒烟：解压 zip → 清除 `SW_TOOLCHAIN` /
  `SW_STDLIB` / `SW_RUNTIME` → 无外部工具链编译联网能力探针
  （probe-batch11，覆盖 ws2_32/ole32 链接）→ 编译并运行 hello。
- 新增 `tools/make-checksums.py`：生成/校验 `SHA256SUMS`（GNU 风格）。
- 新增文档 [docs/09-发布与分发.md](docs/09-发布与分发.md)：SDK 目录结构、
  解压即用方法、三平台构建、发布检查清单。
- `make-sdk.ps1` 支持绝对 `-OutDir`（`Path.Combine`，修复 `Join-Path`
  拼接绝对路径的缺陷），并补齐同样的 6 个链接库。

### 已知限制
- Windows aarch64（COFF）暂不支持；单线程运行时；调试信息待完善。
- 详见「docs/08-能力清单.md」与仓库 README。
