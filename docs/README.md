# Sw 语言规范

本目录是 Sw 语言与 ABI 的唯一规范。新增或修改语法时必须同步更新对应文档和 `docs/grammar/sw.ebnf`。

## 文档顺序

1. [00-设计目标](00-设计目标.md)：语言定位、语法风格、技术路线与 v0.1 裁剪范围
2. [01-词法规则](01-词法规则.md)：UTF-8、标识符、关键字、字面量、注释、运算符
3. [02-语法规则](02-语法规则.md)：声明、语句、表达式、优先级
4. [03-类型系统](03-类型系统.md)：基础类型、转换、推导、泛型
5. [04-内存模型](04-内存模型.md)：值/引用类型、所有权、引用计数、清理
6. [05-模块系统](05-模块系统.md)：文件模块、导入导出、可见性
7. [06-错误处理](06-错误处理.md)：编译期诊断、运行期异常、Option/Result
8. [07-平台与ABI](07-平台与ABI.md)：目标平台、调用约定、C 互操作
9. [08-能力清单](08-能力清单.md)：实测支持的功能清单（模块/全局变量/跨文件引用等）
10. [09-发布与分发](09-发布与分发.md)：三平台 SDK 构建/使用、发布流程、校验和与发布说明

机器可读语法定义见 [grammar/sw.ebnf](grammar/sw.ebnf)。

## 实现阶段

- 阶段 1：词法器 + 语法分析器 + AST + 语法测试
- 阶段 2：名称解析 + 类型检查 + MIR
- 阶段 3：Cranelift 代码生成 + lld 链接 + 最小运行时，形成可执行闭环
- 阶段 4：完整标准库、调试信息、打包分发
