# 01 词法规则

状态：规范基线

## 1. 编码

- 源文件统一使用 UTF-8，解码失败立即报错（不使用替换字符）。
- 标识符按 Unicode 规范化形式 NFC 处理。

## 2. 空白

空格（U+0020）、制表符（U+0009）、回车（U+000D）、换行（U+000A）均为空白。空白只作为 token 分隔符，不参与语法结构。

## 3. 注释

```text
// 行注释：到行尾结束
/* 块注释：可嵌套 */
```

块注释允许嵌套。注释等价于空白，不保留语义。

## 4. 标识符

```text
identifier := ( "_" | "$" | XID_Start ) { "_" | "$" | XID_Continue }
```

- 允许中文等 Unicode 标识符，例如 `let 数量 = 3;`。
- 关键字不能作为标识符。
- 标识符区分大小写；`foo` 与 `Foo` 是两个名字。

## 5. 关键字

正式关键字（保留，不可作标识符）：

```text
async  await  break  case  catch  class  const  constructor
continue  default  defer  destructor  else  enum  export  extends
false  final  finally  for  function  if  implements  import
interface  internal  let  new  null  of  override  private  property
protected  public  return  static  struct  super  switch  this
throw  true  try  type  using  virtual  while
```

`var`、`undefined`、`typeof`、`instanceof`、`do` 是保留的"不支持"关键字：解析器给出明确错误，而不是当作标识符。

上下文关键字（可作标识符，由语法位置识别）：`as`、`from`、`extern`、`native`、`get`、`set`、`where`。

## 6. 字面量

### 6.1 整数

```text
123        十进制
0x1F       十六进制
0b1010     二进制
0o755      八进制
1_000_000  数字分隔符
42u8       后缀：i8 i16 i32 i64 u8 u16 u32 u64 isize usize
```

- 下划线只能出现在数字之间。
- 无后缀字面量的宽度按目标类型适配（见 03 类型系统）。

### 6.2 浮点

```text
3.14      1.5e3     2.0f32     1e10
```

后缀：`f32`、`f64`。无后缀默认 `f64`（即 `float`）。

### 6.3 字符串

```text
"双引号字符串"     支持转义，不支持插值
'单引号字符串'     同上
`模板字符串`       支持 ${expr} 插值、可跨行
```

转义序列：

```text
\0  \t  \n  \r  \"  \'  \`  \\
\x41                十六进制字节（必须在合法 UTF-8 范围内）
\u{1F600}           Unicode 标量值
```

插值 `${ ... }` 内是完整表达式，表达式内允许嵌套字符串。

### 6.4 字符

```text
'a'   '\n'   '\u{4E2D}'
```

字符类型是 Unicode 标量值（`char`），占用 4 字节。

### 6.5 布尔与空值

`true`、`false`、`null`。

## 7. 运算符与分隔符

```text
算术：      +  -  *  /  %  **  ++  --
赋值：      =  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=  ??=
比较：      ==  !=  <  <=  >  >=
逻辑：      &&  ||  !
位运算：    &  |  ^  ~  <<  >>
空值：      ??  ?.  ?:
其他：      =>  ...  @
分隔符：    (  )  {  }  [  ]  ,  ;  :  .
```

不支持 `===`、`!==`、`>>>`。

## 8. 最长匹配与错误

- token 按最长匹配切分；`a+++b` 切为 `a ++ + b`。
- 非法字符、未闭合字符串/注释/模板、非法转义、越界数字后缀均产生词法错误，并带源码行列位置。
