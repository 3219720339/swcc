# 03 类型系统

状态：规范基线

## 1. 内建类型

| 类型 | 含义 | 字节数 |
|---|---|---|
| `bool` | 布尔 | 1 |
| `i8 i16 i32 i64` | 有符号整数（精确宽度） | 1/2/4/8 |
| `u8 u16 u32 u64` | 无符号整数（精确宽度） | 1/2/4/8 |
| `isize usize` | 指针宽有/无符号整数 | 8（64 位平台） |
| `int uint` | 平台默认整数，映射 `isize/usize` | 8 |
| `f32 f64` | 单/双精度浮点 | 4/8 |
| `float` | 默认浮点，映射 `f64` | 8 |
| `char` | Unicode 标量值 | 4 |
| `string` | 不可变 UTF-8 文本（引用类型） | 16（指针+长度） |
| `void` | 仅用于函数返回类型 | 0 |

复合类型：

| 类型 | 含义 |
|---|---|
| `T[]` | 动态数组（引用类型） |
| `T?` | 可空类型：`T` 或 `null` |
| `ptr<T>` | 原生指针（仅 unsafe 上下文解引用） |
| `struct S` | 值类型聚合 |
| `enum E` | 无载荷枚举，底层为整数 |
| `class C` | 引用类型对象 |
| `interface I` | 接口引用，虚表派发 |

## 2. 类型语法

```text
typeReference := typeSegment { "." typeSegment } { "[]" | "?" }
typeSegment   := identifier [ "<" typeReference { "," typeReference } ">" ]
```

示例：`int[]`、`string?`、`Map<string, int[]>`、`std.io.File`。

后缀组合顺序固定：先 `[]` 后 `?`，即 `int[]?` = 可空的数组引用，`int?[]` = 元素可空的数组。

## 3. 字面量类型适配

- 整数/浮点字面量本身无固定宽度；有目标类型标注时按目标类型检查范围。
- `let x: u8 = 300;` 报错（越界）；`let x = 300;` 推导为 `int`。
- 无后缀浮点字面量默认为 `f64`。
- `null` 的类型是空类型，只能赋给可空类型或引用类型。
- 字符串字面量类型为 `string`；模板字符串同为 `string`。

## 4. 转换规则

### 4.1 不允许的隐式转换

- 不同整数宽度之间不允许隐式转换（`let x: i64 = y;` 若 `y: i32` 则报错）。
- 整数与浮点之间不允许隐式转换。
- `bool` 不参与算术，也不允许与整数互相转换。
- 有符号与无符号之间不允许隐式转换。

### 4.2 显式转换

```js
let a: i64 = 1;
let b: i32 = a as i32;      // 显式截断/扩展
let f: float = b as float;  // 整数转浮点
let back: i64 = f as i64;   // 浮点转整数（截断）
let u: u32 = value as u32;  // 按位重新解释宽度转换
```

- `as` 只允许数值类型、`char` 之间的转换，以及 `ptr<T>` 与整数/`ptr<U>` 之间的显式转换。
- 引用类型之间的向上转型（子类 → 父类）是隐式的；向下转型 `as` 在运行时检查并抛异常（v0.2）。

## 5. 类型推导

- 变量：`let x = expr;` 用初始化式推导。
- 函数返回类型：省略时由所有 `return` 分支联合推导，必须一致。
- 箭头函数参数：可从上下文推导（调用处签名已知时）；无法推导且未标注时报错。
- 数组字面量：`[1, 2, 3]` 推导为 `int[]`；空数组 `[]` 必须标注目标类型。
- 对象字面量：必须能确定目标类型（struct/class 初始化或标注的变量），否则报错。
- 泛型：按参数推导实例类型；无法推导的泛型参数必须显式给出。
- 不允许"隐式 any"：任何无法确定类型的表达式都是错误。

## 6. 可空类型

```js
let name: string? = maybe();
if (name != null) {
    println(name.length);   // 窄化后可直接使用
}
let len = name?.length ?? 0;  // 空值安全访问 + 空值合并
```

- 非空引用类型不能赋 `null`。
- `?.` 只对可空类型或引用类型有效。
- 控制流窄化：`if (x != null)` 分支内 `x` 视为非空。

## 7. 泛型

```js
function first<T>(values: T[]): T {
    return values[0];
}

class Box<T> {
    private value: T;
    constructor(value: T) { this.value = value; }
    get(): T { return this.value; }
}

function sort<T>(items: T[]): T[] where T: Comparable {
    ...
}
```

规则：

- 泛型在编译期单态化：每个具体类型实例生成独立代码（MIR 边界）。
- `where T: Interface` 约束接口实现；约束内可调用接口方法。
- 泛型函数可重载；泛型类不能继承具体泛型参数不匹配的类。

## 8. 类与接口

- 类字段、方法、属性访问通过编译期解析；虚方法经 vtable 派发。
- 接口引用调用虚方法；接口不能有字段和构造。
- 向上转型隐式；`override` 必须与父类虚方法签名一致，未标记 `virtual` 的方法不可覆盖。
- `final class` 不可被继承。

## 9. 类型别名

```js
type StatusCode = int;
type Name = string;
```

- 别名只提供源码层面的名字，不创建新类型；别名可互相引用，循环别名报错。

## 10. 类型检查规则摘要

- 所有表达式必须有确定类型。
- 二元运算要求两操作数类型精确匹配（整数可字面量适配）；不匹配报错并要求显式转换。
- `+` 对 `string` 表示拼接（JS 风格）；对数值表示加法；`string + 数字` 报错（不隐式转换）。
- 索引 `arr[i]`：`i` 必须是整数类型；越界是运行期错误。
- 函数调用实参数量与类型必须与签名匹配（顶层重载按参数类型选择）。
