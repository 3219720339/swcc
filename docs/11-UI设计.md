# Sw 跨平台 UI 库设计（docs/11）

> 状态：设计稿（P1 未动工）。目标：跨平台（Windows/Linux/macOS × x86_64/aarch64）、
> 性能好、少依赖、好看、不复杂；链式调用一等支持；后续可输出 dll/lib 供其他语言调用。

---

## 1. 设计原则（铁律 5 条）

1. **窗口后端线程永不执行 Sw 代码**——事件数据化（与 std/audio 同原则："音频线程不回调 Sw 代码"）。
2. **所有原生状态在 C 内存**，Sw 侧只见 `ptr<void>` handle。
3. **`sw_ui_*` 是纯 C 风格 API**（handle + int/float + C 字符串），为将来 dll 输出铺路。
4. **渲染器可替换**（NanoVG GL / AGGE 软件），编译期开关，Sw API 不变。
5. **Canvas 坐标一律逻辑像素**，DPI 在平台层换算。

关键推论（GC 安全）：运行时 GC 是协作式 safepoint 停世界（`sw_gc_stop_world` → 线程在
`sw_gc_safepoint()` 停驻）。Sw 线程阻塞在 native 时不会停驻，GC 会自旋等待——因此
**`pump(timeout_ms)` 必须总有界返回（推荐 16ms），任何 Sw 线程不得在 native 里无限阻塞**。

## 2. 架构总览

```
┌──────────────────────────────────────────────────────┐
│ examples/demo-ui.sw · probe-ui.sw          （演示）   │
├──────────────────────────────────────────────────────┤

│ stdlib/ui.sw          Sw 绑定（稳定 API）   （P1）    │  ← 永不因后端变化而变
├──────────── ABI 分界线：sw_ui_* extern C 函数 ────────┤
```

+ `stdlib/audio.sw` + `main.rs compile_runtime_objects` 加编译 task + SDK 打包 `runtime_audio.obj`。

## 3. `runtime_ui.c` C API 表

### 生命周期
```c
void* sw_ui_create(const char* title, int width, int height); // 失败返回 NULL
void  sw_ui_destroy(void* h);
int   sw_ui_is_open(void* h);            // 未收到关闭请求
void  sw_ui_close(void* h);
void  sw_ui_set_title(void* h, const char* title);
void  sw_ui_set_size(void* h, int w, int h);   // 请求尺寸，结果看 RESIZED 事件
int   sw_ui_last_error(void* h);         // 0 无错误
```

### 事件循环（铁律：timeout 有界）
```c
int   sw_ui_pump(void* h, int timeout_ms);      // 返回本次新事件数
int   sw_ui_event_poll(void* h);                // 弹出一条 kind，无则 0
int   sw_ui_event_a(void* h);                   // b / c / d 同理
int   sw_ui_event_text(void* h, char* buf, int cap); // P2：UTF-8 文本拉取
```

### 杂项
```c
int   sw_ui_get_scale(void* h);            // DPI ×1000，整数避免 ABI 歧义
void  sw_ui_set_cursor(void* h, int cursor);
```

### 绘制（P2，命令追加式）
```c
void  sw_ui_canvas_clear(void* h, uint32_t color);              // 0xAARRGGBB
void  sw_ui_canvas_fill_rect(void* h, float x, float y, float w, float h, uint32_t color);
void  sw_ui_canvas_fill_round_rect(void* h, float x, float y, float w, float h, float r, uint32_t color);
void  sw_ui_canvas_stroke_round_rect(void* h, float x, float y, float w, float h, float r, float stroke_w, uint32_t color);
void  sw_ui_canvas_fill_circle(void* h, float cx, float cy, float r, uint32_t color);
void  sw_ui_canvas_fill_linear_gradient(void* h, float x0, float y0, float x1, float y1, uint32_t c0, uint32_t c1);
void  sw_ui_canvas_draw_text(void* h, float x, float y, float size, const char* text, uint32_t color); // 左上对齐
float sw_ui_canvas_text_width(void* h, float size, const char* text);
int   sw_ui_present(void* h);              // 重放命令→渲染→交换；0 成功
```

错误码：`0` 无 / `1` 平台初始化失败 / `2` 创建窗口失败 / `3` GL 上下文失败 /
`4` 渲染后端不可用 / `5` 命令表溢出 / `6` 字体加载失败。

## 4. 事件协议（纯 int 数据，零分配）

`UiEvent { kind, a, b, c, d }`：

| kind | 名称 | a | b | c | d |
|---|---|---|---|---|---|
| 0 | NONE | – | – | – | – |
| 1 | CLOSE_REQUESTED | – | – | – | – |
| 2 | RESIZED | 新宽 | 新高 | – | – |
| 3 | KEY | scancode | 按下=1 | 重复=1 | 修饰位掩码* |
| 4 | CURSOR | x | y | – | – |
| 5 | MOUSE_BUTTON | 1左/2右/3中 | 按下=1 | – | – |
| 6 | MOUSE_WHEEL | 横向 | 纵向(×100) | – | – |
| 7 | FOCUS | 获得=1 | – | – | – |
| 8 | SCALE_FACTOR | ×1000 | – | – | – |
| 9 | REDRAW | – | – | – | – |
| 10 | TEXT_INPUT | – | – | – | UTF-8 经 `sw_ui_event_text` 拉取 |

\* 修饰位：bit0 Shift / bit1 Ctrl / bit2 Alt / bit3 Super。物理 scancode 与键盘布局无关，
字符输入走 TEXT_INPUT。事件队列：C 侧环形缓冲（256×20B），溢出丢弃最旧。

## 5. `stdlib/ui.sw` 接口（链式调用一等支持）

**链式设计约定**：所有 setter / 绘制方法返回 `this`，主循环方法返回 bool / void——
与 std/string 的链式先例一致（`return this;`）。绘制命令天然成链：
`canvas.clear(c).fill_round_rect(...).draw_text(...).present()`。

```sw
// std/ui
export const UI_EVENT_NONE = 0;        // …全部常量见事件表
export const CURSOR_DEFAULT = 0;  export const CURSOR_HAND = 1;
export const CURSOR_TEXT = 2;     export const CURSOR_WAIT = 3;

export struct UiEvent { kind: int; a: int; b: int; c: int; d: int; }

export function rgb(red: int, green: int, blue: int): int;   // 0xFFRRGGBB
export function rgba(red: int, green: int, blue: int, alpha: int): int;

export class Application {
    public constructor(title: string, width: int, height: int);
    public function pump(timeout_ms: int): bool;        // true=窗口仍开
    public function is_open(): bool;
    public function poll(): UiEvent;

    // —— 链式：setter 返回 this ——
    public function set_title(title: string): Application;
    public function set_size(width: int, height: int): Application;
    public function request_redraw(): Application;
    public function set_cursor(cursor: int): Application;

    public function scale(): int;                       // DPI ×1000
    public function last_error(): int;
    public function close(): void;                      // 终止型
    public function destroy(): void;                    // 终止型
}

// P2 追加 Canvas（链式）：
// canvas.clear(c).fill_rect(...).fill_round_rect(...).fill_circle(...)
//       .fill_linear_gradient(...).draw_text(...).present();
```

主循环范式（GC 安全 + 空闲零 CPU）：

```sw
const app = new Application("demo", 800, 600);
while (app.pump(16)) {            // 有界阻塞；空闲时线程睡眠
    while (true) {
        const ev = app.poll();
        if (ev.kind == UI_EVENT_NONE) break;
        // 分发…
    }
    // 更新逻辑 + 绘制（P2）
}
app.destroy();
```

## 6. Win32 后端设计（P1 主战场）

- **线程模型**：窗口建在调用线程（Sw 线程即 UI 线程）；`pump()` 内
  `MsgWaitForMultipleObjectsEx(QS_ALLINPUT, timeout)` + `PeekMessage` 循环——
  精确超时、输入即醒、空闲即睡。
- **WndProc → 事件队列**：`WM_CLOSE→CLOSE_REQUESTED`、`WM_SIZE→RESIZED`、
  `WM_KEYDOWN/UP→KEY`（lParam>>16 scancode + GetKeyState 修饰）、
  `WM_MOUSEMOVE→CURSOR`、`WM_LBUTTONDOWN/UP→MOUSE_BUTTON`、`WM_MOUSEWHEEL→WHEEL`、
  `WM_DPICHANGED→SCALE_FACTOR`、`WM_CHAR→TEXT_INPUT`（P2）。
- **DPI**：`SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)` + `GetDpiForWindow`，
  全部 `GetProcAddress` 探测，缺失（Win7）降级 96 DPI。
- **present（P2）**：`SwapBuffers`（GL）；软件后端 `StretchDIBits`。

---

## 7. 渲染管线（P2）

- 命令缓冲：C 侧动态数组（每条 32-64B：type+参数），上限 64K 条防爆。
- `present()`：`nvgBeginFrame(w, h, scale)` → 重放（逻辑像素统一 ×scale）→
  `nvgEndFrame` → 交换。
- **双后端**：默认 GL（wgl / GLX / Cocoa NSOpenGLView）；`#define SW_UI_USE_AGGE`
  走软件后端——CI 无头环境用软件渲染做像素冒烟。
- 暂不做脏矩形（几百图元全量重绘 60fps 无压力），留优化位。

---

## 8. 字体（P2）

- 加载顺序：系统字体探测（Win `msyh.ttc`→`simhei.ttf`；mac PingFang；
  Linux 常见路径）→ 内嵌拉丁兜底（Inter 子集 ~100KB，编成 .c 数组）。
- stb_truetype 已内嵌于 NanoVG，无需额外代码。
- 单字体单字号起步；P2 末加字号缓存。

## 9. 构建接入（照抄音频模式）

1. `main.rs compile_runtime_objects`：加 `runtime_ui.c` task（含 `SW_NO_MAIN` 变体）。
2. vendor 纳入 SDK 打包的 vendored-headers 处理（main.rs 已有 miniaudio 先例）。
3. `make-sdk.py / make-sdk.ps1`：加 `runtime_ui.obj`；CI SDK smoke 校验存在。
4. CI：ubuntu runner `apt install libx11-dev libgl1-mesa-dev xvfb`；`runtime_ui.c` 顶部
   ```c
   #if defined(_WIN32) || (defined(__linux__) && __has_include(<X11/Xlib.h>)) \
       || (defined(__APPLE__) && __has_include(<Cocoa/Cocoa.h>))
   // 真实现
   #else
   // stub：sw_ui_create 返回 NULL、其余安全 no-op（musl 交叉编译自动退化）
   #endif
   ```
5. 普通 exe 体积不变：`--gc-sections` 自动裁掉未引用 UI 代码。

## 10. dll / lib 输出（P3）

- 已知坑：`main.rs` 的 .def 生成跳过 `extern_c` 函数，而 `sw_ui_*` 定义在 C 侧——
  dll 版需在 .def 追加 `sw_ui_*` 符号（固定符号表或独立 sw_ui.def）。
- 纯 C 核心对第三方语言零障碍（handle + int + C 字符串）。
- Sw 控件层跨语言需嵌入 Sw 运行时 + 边界处理（外来线程 GC 注册、异常转错误码、
  字符串拷贝）——P3 再定。
- 预留"注册绘制回调"钩子（C 函数指针），其他语言可自绘。

## 12. Windows 7 兼容（专项分析）

**结论：可支持，前提 Win7 SP1 + 已装 UCRT 更新（KB2999226），UI 代码按降级策略编写。**

| 项 | 现状 / 对策 |
|---|---|
| CRT | 当前全编译器链接 UCRT（`-lucrt -lucrtbase`）。UCRT 在 Win7 需 SP1 + KB2999226（微软官方通道，2015-10 起，装机率极高）。未装更新的裸 Win7 报"缺少 ucrtbase.dll"——**与 UI 无关，是编译器现有行为** |
| DPI API | `SetProcessDpiAwarenessContext`(Win10 1703+)、`GetDpiForWindow`(Win10 1607+)：全部 `GetProcAddress` 探测，缺失则 96 DPI + 不声明 aware（系统位图缩放） |
| DPI 事件 | `WM_DPICHANGED` 仅 Win8.1+；Win7 无事件，scale 恒 1.0 |
| OpenGL | Win7 常见 GPU 驱动支持 GL 2.0+（NanoVG GL2 需要）；驱动仅 1.1 时自动回退 AGGE 软件后端 |
| vsync | `DwmFlush` 仅 Win8+；Win7 跳过，用 pump(16) 定时 |
| 系统字体 | `msyh.ttc`（微软雅黑）Win7 自带，中文 OK |

若需**无更新的裸 Win7**：需编译器整体改链 `-lmsvcrt`（旧 CRT，全 Windows 自带），
属独立任务、影响所有程序，不建议现阶段做。

## 13. 风险与对策

| 风险 | 对策 |
|---|---|
| Cocoa 必须主线程 | runtime_ui.c 内部 `dispatch_sync` 转发，Sw 无感 |
| CI 无 GPU | AGGE 软件后端渲染冒烟；GL 真机验证 |
| 无头环境（SSH/容器） | 创建失败返回错误码，不崩溃 |
| musl 静态不能链 X11/GL | `__has_include` stub 退化禁用 |
| NanoVG 编译耗时 | `.swcache/obj` 探针缓存，每目标一次 |
| 许可证 | nanovg=zlib、stb=public domain、agge=MIT，均无问题 |
