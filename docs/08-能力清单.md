# 08-能力清单（v0.1 实测状态）

> 本文档按「当前编译器实测可用」为准，与语法规范（02/03/05）配套。
> 每条都对应 examples/ 下的可运行探针；新增能力必须同步更新本文档与探针。

## 一、多文件模块（导入其他 .sw 文件）

一个 `.sw` 文件就是一个模块。用 `import` 引用其他文件，用 `export` 对外暴露。

### 1. 命名导入（推荐）

```sw
// lib-geo.sw
export struct Point { x: int; y: float; }
export class Vector { dx: int; dy: int; }
export function make_point(x: int, y: float): Point { ... }

// 使用方
import { Point, Vector, make_point } from "./lib-geo";
const p: Point = { x: 1, y: 2.5 };
const v = new Vector(2, 3);
```

支持 `as` 别名：`import { Point as P } from "./lib-geo";`

### 2. 通配导入

```sw
import * from "./lib-geo";   // 模块全部导出展开进当前作用域
```

### 3. 命名空间导入（副作用导入升级版）

```sw
import * as geo from "./lib-geo";        // 别名命名空间
const p = geo.make_point(1, 2.5);        // 命名空间.名称 调用
```

`import "./path"` 不写 `as` 时以文件名为命名空间（不含扩展名）；
文件名含 `-` 等非标识符字符时必须用 `import * as 别名` 形式。

### 4. 标准库

```sw
import { println } from "std/io";
import { format } from "std/string";
```

标准库模块：`std/io`、`std/fs`、`std/os`、`std/string`、`std/math`、
`std/time`、`std/json`、`std/unicode`、`std/encoding`、`std/net`、
`std/array`、`std/map`、`std/result`、`std/test`、`std/hash`、
`std/regex`、`std/http`、`std/url`、`std/csv`、`std/set`、`std/ini`、
`std/toml`、`std/table`、`std/console`。

### 5. 可导出的顶层声明

`export` 可修饰：`function`、`class`、`struct`、`interface`、`enum`、
`type` 别名、顶层 `const` / `let` 变量。未加 `export` 的名称仅模块内可见，
跨文件导入未导出的名称会报错。

## 二、全局变量（顶层 const / let）

### 1. 模块内全局

```sw
const VERSION = 3;       // 顶层常量
let counter = 10;        // 顶层可写变量（全局数据段，GC 之外）
```

任意函数内可直接读写。

### 2. 跨文件全局（导出 + 导入）

```sw
// lib-vars.sw
export const VERSION = 3;
export let counter = 10;
export function bump(): int { counter += 1; return counter; }

// 使用方（probe-vars.sw）
import { VERSION, counter, bump } from "./lib-vars";
println(VERSION);        // 3
bump();
println(counter);        // 11（读写同一份全局数据，跨模块共享）
```

实现要点：定义模块把全局导出为 `sw_global_<模块>_<名字>` 链接符号；
引用模块按同名声明 Import，读和写都解析到同一份数据，别名导入同样正确。

### 3. 当前限制

- 全局变量初始化目前只支持编译期常量（整数/布尔/字符等），
  浮点/字符串/数组字面量初始化尚未验证。
- 全局变量在链接层按数据符号共享，不支持跨线程（运行时单线程）。

## 三、跨文件引用（模块互操作）

| 被引用内容 | 支持 | 探针 |
| --- | --- | --- |
| 顶层函数 | ✅ | probe-multifile / probe-vars |
| struct 类型 + 字面量 + 字段 | ✅ | probe-multifile |
| struct 相等比较 | ✅ | probe-multifile |
| class（new、字段、方法） | ✅ | probe-multifile |
| 接口（implements、vtable 派发） | ✅ | probe-interface |
| 顶层 const / let 全局（含写入） | ✅ | probe-vars |
| 泛型函数（调用点实例化） | ✅ | probe-generic |
| 泛型约束 `where T: Shape`（约束内调接口方法） | ✅ | probe-trait |
| 泛型约束 `where T: Container<int>`（泛型接口实参） | ✅ | probe-generic-iface |
| 泛型类 `implements` 接口（含 `implements Container<T>`） | ✅ | probe-trait / probe-generic-iface |
| 嵌套泛型（`Box<Box<int>>`、`Container<Box<int>>`） | ✅ | probe-generic-implements |
| 泛型类继承泛型类（`SubBox<T> extends Box<T>`）+ 接口 | ✅ | probe-generic-implements |
| 泛型类/接口/struct 用于泛型函数签名（`make<T>(x: T): Box<T>`、`wrap<T>(x: T): Container<T>`、`Pair<A,B>` 返回） | ✅ | probe-generic-signature |
| 跨模块类 + 接口（vtable 派发，泛型/非泛型） | ✅ | probe-cross-module-iface |
| 带数据枚举（ADT）+ 泛型枚举 + match | ✅ | probe-adt |
| `Result<T, E>` + `?` 错误传播 | ✅ | probe-result |
| `@test` 内嵌测试 + `swc test` | ✅ | probe-test |
| 循环 import（两个 .sw 互相调用） | ✅ | probe-circular |

## 四、其余语言能力速览

- 类型：`int`/`float` 及固定宽度 `i8/i16/i32/i64/u8/u16/u32/u64/
  isize/usize/f32/f64`（字面量支持 `3u8`、`2i32`、`1.5f64` 等后缀）、
  `bool`、`char`、`string`、`u8[]`、数组、`struct`、`class`、
  `interface`、`enum`（含带字段变体 ADT）、可空 `T?`、`any`（varargs）
- 表达式：算术/位/比较/逻辑、`**` 幂、`%`（整数与 fmod）、三元、
  赋值表达式、`++/--`（前后缀）、可选链 `?.`、模板字符串、
  对象/数组字面量、`as` 转换、闭包（值捕获）、`expr?`（Result 错误传播）、
  数组切片 `a[1:3]` / `a[:2]` / `a[2:]`（复制新数组）
- 语句：`if/else`、`while`、`for`（C 式与 `for (x of xs)`）、
  `switch`、`try/catch/finally`（自包含异常运行时）、`break/continue`、
  `return`、`match (v) { Variant(x) => { ... }, _ => { ... } }`
  - `switch`：互斥匹配（无 fall-through），`case` 可省略 `break`，
    `default` 为兜底分支；`break` 在 `switch` 内合法并结束当前 case
  - `match`：ADT 模式匹配（解构变体字段）、穷尽检查、`_` 通配
  - `match` 表达式：`const x = match (v) { Some(n) => n, None => 0 };`
    （分支体为表达式，可作返回值）
- 展开/解构：`[...a, ...b]`、`{ ...origin, y: 9 }`、`f(...[1,2,3])`、
  `const [a, b] = arr;`、`const { x, y } = p;`、`{ x: renamed }` 重命名
- 逻辑赋值：`&&=`、`||=`（`??=` 已有）
- 函数：默认参数、可变参数 `...args: any`（配合 `format`）、
  泛型函数（`where T: 接口` 约束）、递归、闭包、`extern c` 互操作
  - 泛型函数签名可用泛型类型：`function make<T>(x: T): Box<T>`、
    `function read<T>(b: Box<T>): T`、`Box<Box<T>>` 嵌套返回、
    `function wrap<T>(x: T): Container<T>`（泛型接口返回）、
    `function pair<A, B>(...): Pair<A, B>`（泛型 struct 返回）、
    泛型类方法返回泛型类（`Factory<T>.make_box(): Box<T>`）
  - 默认参数：调用时缺参自动补默认表达式，`add(4)` == `add(4, 1)`
  - 函数重载：顶层函数与类方法都支持（按参数类型/个数选择签名）
  - 文本处理：`is_blank`/`strip_whitespace`/`substring_between`（左/右向）、
    `extract_between`（批量）、`before`/`after`（含 last 版）、`char_code`、
    `replace_pairs`（成对连续替换）——全部 UTF-8 中文安全、可链式
  - 中文函数名：std/string 提供火山风格中文别名（取文本中间/是否空白/
    连续子文本替换等，链式同样可用），底层映射到英文实现
  - 时间处理（std/time）：字段提取 `year_of/month_of/day_of/hour_of/
    minute_of/second_of/weekday_of`（Windows SYSTEMTIME / POSIX
    localtime_r 双平台）、`weekday_cn` 中文星期、`time_string`/`iso_string`
    格式化、`format_duration`（秒转 "00:01:30"/中文/含天）、
    `days_in_month`/`days_in_year`、`shift_time`（本地日期增减，DST 安全）、
    `time_diff`、`uptime_ms`；另有 16 个中文函数名（取现行时间戳/取年份/
    取星期文本/时间戳增减/秒数转时间格式等）
- 数组方法：`arr.map(fn)` / `arr.filter(fn)`（编译器内联循环，可链式）、
  `forEach/some/every/find`、`push/pop`、`sort_int/sum_int/reverse_int` 等
  （std/array）
  - 实用（std/array）：`concat_*` 合并、`insert_*` 插入（越界钳制）、
    `remove_at_*` 删除（越界原样复制）、`unique_int/float` 去重、
    `min/max_index_float` 极值位置（均返回新数组，不原地改）
- 文本实用（std/string，纯 Sw 组合）：`replace_first/replace_last`、
  `split_once`（→string[2]）、`count_words`、`pad_center`、
  `common_prefix/common_suffix`（UTF-8 安全）、`swap_case`、`zfill`；
  中文别名（替换首次出现/拆分一次/取单词数/居中填充/取公共前缀/
  大小写互换/前补零等）
- 进程增强（std/os）：`run_with_env`（map 传环境变量）、`run_in_dir`
  （指定工作目录）、`run_stdout_stderr`（→string[2] 分开捕获 stdout/stderr；
  输出超管道缓冲可能阻塞）、`is_process_running(pid)` 存活检测
- 文件增强（std/fs）：`is_writable`、`file_age_sec`（mtime 距今秒数）、
  `dir_size`（目录递归字节数，纯 Sw 组合 walk_files+file_size_path）
- JSON 读路径（std/json，纯 Sw 组合）：`json_get_path`（点路径 a.b.c）、
  `json_has`、`json_object_len`、`json_merge`（b 覆盖 a 返回新对象）
- 网络增强（std/net）：`net_connect_timeout`（带超时连接）、
  `net_set_recv_timeout`/`net_set_send_timeout`（收发超时）、
  `net_available`（可读字节）、`net_resolve`（域名→IP）、
  `net_peer_ip`/`net_peer_port`（对端信息）、`net_set_keepalive`（TCP
  心跳）、`net_recv_until_close`（读到关闭）、`net_send_all`（完整发送）
- 哈希补齐（std/hash）：`crc32`/`crc32_file`（IEEE，check 0xCBF43926）、
  `crc16`（IBM，check 0xBB3D）、`sha1`/`sha1_file`（40 位 hex）、
  `hmac_sha256`（RFC 4231 向量）
- 人性化时间（std/time，纯 Sw）：`time_ago_cn`/`time_ago_en`（刚刚/
  N 分钟前/小时前/天前/周前/月前/年前）、`month_name`/`weekday_name`
  （英文名）、`days_between`/`hours_between`/`minutes_between`
- 其他实用（纯 Sw 为主）：`map_get_or`（map 默认值）、
  `set_union`/`set_intersect`/`set_difference`（集合运算）、
  `csv_read_all`/`csv_write_all`（批量 CSV）、`chunk_int/float/string`
  （数组分块）、`http_get_json`（GET 后直接解析 JSON）
- 常用基础（批 9，纯 Sw 为主）：`char_at`/`left`/`right`（UTF-8 取字符/
  前/后 n 字符）、`starts_with_any`/`ends_with_any`（多前缀后缀匹配）、
  `edit_distance`（莱文斯坦距离）、`factorial`/`is_prime`/`next_prime`/
  `percent`/`round_to`/`lerp`（数值基础）、`flatten_string`、
  `first_*`/`last_*`（空数组回退，int/float/string）、`avg_float`、
  `map_merge`/`map_from_arrays`（map 构建合并）、`flush`（冲刷 stdout）、
  `console_clear_line`/`console_title`（终端行/标题）、`memory_usage_kb`
  （进程内存）
- 进程交互（批 10，std/os）：`process_open`（保持管道逐步交互）、
  `process_write`/`process_read_line`/`process_read_some`/`process_poll`
  （非阻塞查输出）、`process_wait`/`process_kill`/`process_close`/
  `process_close_input`（关闭 stdin 触发 EOF；sort 等工具）
- 终端按键/进度条（批 10，std/console）：`read_key`（方向/功能键扩展码
  1000+/F1-F12）、`progress_text`/`console_progress`（动态进度条，纯 Sw
  组合清行+冲刷）
- 交互 IO（std/io + std/console）：`input(prompt)`/`input_int`/`input_float`
  （提示 + 读取 + 无效重试，纯 Sw 组合）、`print_format(fmt, ...)`（printf
  风格直接输出）、`console_color(fg,bg)`/`console_reset`/`console_clear`/
  `console_gotoxy`/`console_hide_cursor`/`console_show_cursor`（ANSI 转义，
  Windows 启动自动启用 VT 模式）、`getch()`（读键不回车）、
  `console_width`/`console_height`（重定向时返回 0）；全中英文函数名
  （输入文本/输入整数/输入小数/格式化输出/置颜色/清屏/读按键/取终端宽度等）
- 类：继承（`extends` + `super()`/`super.method()`）、字段、方法、
  构造、方法覆盖、`implements` 接口；派生类继承基类接口并在虚表中
  保留/覆盖实现
  - 泛型类 `implements`：`implements Container<int>`（具体实参）、
    `implements Container<T>`（依赖类类型参数，实例化时替换并注册 vtable）、
    多接口、多类型参数
  - 泛型类继承：`SubBox<T> extends Box<T>`（基类实参可为自身类型参数）、
    多级继承、`extends Box<int>` 具体实参 + 自身 implements
  - implements 校验：类必须实现接口全部方法，且方法签名（参数/返回类型，
    接口类型实参替换后）必须兼容；缺方法/类型不符编译报错；
    泛型接口 implements 必须带类型实参
  - `static` 字段（标量，类级全局）与 `static` 方法（无 this）
- 内存：保守式标记-清除 GC（字符串/数组/类/闭包/异常对象），
  无手动 free；值类型按值拷贝
- 入口：`function main(): int`，可带 `main(args: string[])`；
  `swc run` 把进程 argv 透传给程序
- 测试：`@test function name(): int`（0 通过/非 0 失败，无 main 时自动合成
  runner，`swc test <file>` 逐个运行并输出 `[ok]/[FAIL]`，退出码=失败数）
  - `std/test` 断言：`assert(cond[, msg])`、`expect_eq<T>`（标量/struct/
    可空按值比较）+ 数组重载（int[]/float[]/string[] 逐元素）、
    `expect_true/expect_false/fail`；断言失败抛异常，runner 捕获记为 [FAIL]
- 平台：Windows / Linux / macOS × x86_64 / aarch64；
  Linux 支持 musl 静态链接；零 clang 依赖（Cranelift + 内嵌 lld）
- 构建产物：swcc.toml 配置 `[build] kind` —— `console`（exe，默认）/
  `dll`（Windows .dll+导入库、Linux .so、macOS .dylib）/
  `lib`（静态库 .lib/.a，llvm-ar 打包）；`[lib] name` 决定产物名
  - 程序元数据（swcc.toml `[project]`）：name/version/description/
    author/copyright/icon/language（语言：zh-CN / en-US，默认简体中文）、
    entry（默认入口：swc run/check/build 不带文件名时使用，缺省 main.sw）
  - Windows：版本信息（属性页）自动嵌入 exe 与 dll，`icon` 指向 .ico
    文件（相对 swcc.toml 目录）一并嵌入
  - macOS：版本信息嵌入 Info.plist 段（Finder 属性可见）
  - Linux：ELF 无标准版本资源机制，版本信息通过运行时/包元数据提供
  - `swc init [-y]`：在当前目录生成默认 swcc.toml（-y 覆盖已存在文件）

> 综合示例：`examples/showcase.sw`（`swc run examples/showcase.sw`）
> 一口气覆盖上述大部分能力，是快速验证编译器完整度的入口。

## 五、已知限制（v0.1）

- Windows aarch64（COFF）暂不支持（Cranelift 对象写入器限制）
- 单线程：异常帧为全局栈，多线程留待后续
- 泛型 enum 用于泛型函数签名/返回类型（如 `Option<T>` 返回值）未专门验证
- 对象字面量直接作为 return/实参（无目标类型传播上下文）需先赋给类型化变量
- 泛型接口实例化按类型实参缓存；同一接口不同实例（Container<int> /
  Container<string>）各自独立 vtable 槽位
- `var`、`undefined`、`typeof`、`instanceof`、`do` 为保留关键字（明确报错）
- 全局变量初始化限编译期常量（见上）
- 调试信息 / LSP / 格式化器未提供（v0.2 计划）
