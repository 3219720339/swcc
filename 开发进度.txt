Sw 编译器（swcc）开发进度
==========================

更新：2026-08-14（main）

一、已完成

1. 项目基建
   - Rust workspace：sw_common / sw_frontend / sw_semantic / sw_codegen_cranelift / swc
   - 私有仓库：Gitee https://gitee.com/YJTXJH/swcc.git（main）
   - 规范文档：docs/00~07、docs/grammar/sw.ebnf

2. 前端（纯 Rust，无外部依赖）
   - 词法器 / 语法分析器 / AST；JS 风格语法（let/const、function、class、
     箭头函数、模板字符串、import/export）

3. 语义层
   - 名称解析、类型检查、MIR 生成；import 模块系统

4. 后端（Cranelift 进程内代码生成，零 clang 依赖）
   - MIR → 机器码 → COFF/ELF/Mach-O 对象 → lld 链接 → 可执行文件
   - 三元表达式、异常（自包含 setjmp/longjmp，非 CRT）、闭包（值捕获+间接调用）
   - 数组、类、for-of、模板字符串、复合赋值

5. 跨平台与分发
   - 按 triple 编译：Windows / Linux / macOS × x86_64 / aarch64
   - Linux x86_64 / aarch64 musl 静态链接（aarch64 用 rustup compiler-builtins
     补齐 128 位软浮点辅助函数）
   - macOS 原生链接（系统 cc 编译运行时并链接，Mach-O 符号自动加下划线）
   - Windows SDK 打包：swc + lld + MinGW UCRT 库 + 预编译运行时，解压即用
     （dist/swc-windows-x64.zip，已验证无外部工具链可构建运行）

6. CI（.github/workflows/ci.yml，仓库在 Gitee，需镜像到 GitHub 触发）
   - Windows / Ubuntu / macOS 三平台矩阵，自动下载 llvm-mingw 20260616
   - cargo fmt 检查 + 全量测试 + release 构建 + 三平台冒烟 + SDK artifact

7. 表达式与后端补齐（本批）
   - struct 值语义全链路：字面量、参数按地址传（被调方复制）、sret 返回值、
     字段读写、按值拷贝（`let b = a` 后互不影响）
   - `**` 幂运算：整数快速幂、浮点走 libm pow
   - `++/--` 表达式：前缀返回新值、后缀返回旧值
   - 赋值表达式：`a = b` 整体返回被赋的值（含复合赋值）
   - 后端浮点支持补齐：局部/参数/返回值、加减乘除、比较、三元、`%`（fmod）、
     自增、float 转字符串
   - 防护：struct 嵌套字段/struct 数组/类字段存 struct 明确报错，避免按值语义被破坏

8.（上一批结束时）测试：37 项全过（词法 10 / 语法 12 / 语义 8 / 代码生成 7），示例端到端验证

9. 本批（CLI / 标准库 / 泛型 / 内存管理）
   - CLI：`swc help`、`--version`、构建耗时输出（构建成功时打印用时 ms）
   - 标准库：`std/io`（print/println/read_line）、`std/math`（abs/min/max/floor/ceil/sqrt）、
     `std/fs`（open/close/write/read_all）、`std/string`（index_of/contains/starts_with/substring）
   - 泛型函数端到端：调用点单态化（推断类型实参、生成并缓存专用实例、支持自递归），
     类型替换覆盖局部/转换/数组/结构体；模板函数本身不再生成 MIR
   - 内存管理：运行时保守式标记-清除 GC（原生栈 + 寄存器溢出区 + 程序数据段 + 堆内引用扫描），
     字符串/数组/class/闭包统一走 GC 分配器，按阈值自动回收；30 万次分配压力测试通过
   - 顺手修复存量 bug：调用结果类型未登记（`f().length` 解析失败）、字符串 `.length` 偏移、
     字符串 for-of 元素类型、成员链 span 碰撞导致的类型误判

二、已知限制

- Windows aarch64（COFF）暂不支持：Cranelift 对象写入器未实现 AArch64 COFF 重定位
- 单线程：异常帧栈为全局变量，多线程留待后续版本
- 调试信息与错误诊断体验待完善（v0.2）
- struct 嵌套/struct 数组/类字段存 struct 暂不支持（v0.1 显式报错）
- 浮点全局变量未验证（全局按 64 位常量槽存储）
- GC 为保守式：异常帧/抛出对象暂不参与回收，高频抛异常可能累积少量内存
- 泛型仅支持本模块函数实例化；泛型 struct/class 暂未支持
- Windows aarch64（COFF）仍受 Cranelift 对象写入器限制
